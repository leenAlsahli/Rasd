# رصد (Rasd)

## التشغيل
1. `pip install -r requirements.txt`
2. انسخ مجلدي الموديلين إلى `models/` (التفاصيل في models/README.txt)
3. `python app.py` (أو run.bat على ويندوز / run.sh على ماك ولينكس)
4. افتح http://127.0.0.1:8000

لمعاينة الواجهة بدون الموديل: `run_demo.bat` أو `RASD_DEMO=1 python app.py`
(نتائج Demo بقواعد كلمات بسيطة وليست من الموديل).

إذا ما وجد الموديلات يطبع رسالة واضحة ويوقف، ولا يشتغل بالـ Demo تلقائيًا.
